# DrivenSpin

A driven two-level system (a spin, or a qubit) simulated in
[Julia](https://julialang.org/), set up as a
[DrWatson](https://juliadynamics.github.io/DrWatson.jl/stable/) project. It is the
playground of the hands-on session of the course *AI for Physics Projects*, and an
example of the project layout the course recommends.

This folder is **stage 1**: coherent Rabi oscillations, with tests. The hands-on adds
decoherence, Ramsey and echo sequences, and a fit to synthetic data; see
[`exercises/`](exercises/README.md).

## Run it

From this folder:

```bash
julia --project -e 'using Pkg; Pkg.instantiate()'
julia --project -e 'using Pkg; Pkg.test()'
julia --project scripts/rabi.jl
```

The first line installs the exact package versions of `Manifest.toml`. The second
runs the tests. The third simulates Rabi oscillations, saves the results in
`data/sims/rabi/` (each file records the git commit of the code that made it) and
plots them in `plots/rabi.png`.

## Layout

```
DrivenSpin/
|-- src/DrivenSpin.jl    # the physics: functions, no hard-coded parameters
|-- scripts/rabi.jl      # parameters, calls to src/, saved results and plots
|-- test/runtests.jl     # the physics checks
|-- exercises/           # hands-on instructions and the planted bug
|-- data/, plots/        # generated by the scripts; not in git
|-- Project.toml         # dependencies
|-- Manifest.toml        # exact versions
|-- AGENTS.md            # conventions and rules for AI agents (and for you)
|-- CLAUDE.md            # points Claude Code to AGENTS.md
|-- .claude/skills/      # procedures loaded on demand (fit-ramsey)
`-- .github/workflows/CI.yml   # runs the tests on GitHub on every push
```

## Conventions

ħ = 1; times in μs and angular frequencies in rad/μs. Basis (|e⟩, |g⟩), and the
rotating-frame Hamiltonian H = (Δ/2)σz + (Ω/2)σx with detuning Δ = ω_q − ω_d and
Rabi frequency Ω. The full list is in [`AGENTS.md`](AGENTS.md).
